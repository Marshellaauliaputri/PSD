Implementasi K-Means Clustering dalam Pengelompokan Data Kualitas Udara Berdasarkan Polutan CO, NO₂, dan SO₂ di Kecamatan Kalianget.#

Analisis ini membahas proses pengelompokan data wilayah berdasarkan karakteristik polutan CO, NO₂, dan SO₂ menggunakan metode K-Means Clustering. Data polutan yang digunakan terlebih dahulu melalui proses preprocessing dan ekstraksi fitur menggunakan TSFEL (Time Series Feature Extraction Library). Hasil ekstraksi fitur tersebut kemudian digunakan sebagai dasar dalam proses pengelompokan.

Penerapan K-Means bertujuan untuk mengetahui kelompok data yang memiliki karakteristik polutan yang relatif mirip. Dengan adanya proses clustering, pola kemiripan antarwilayah berdasarkan karakteristik polutannya dapat lebih mudah diamati dan dianalisis.

1. Penerapan K-Means Clustering dengan Python#

Proses clustering pada data polutan dapat diimplementasikan menggunakan bahasa pemrograman Python dengan memanfaatkan library Scikit-Learn (sklearn). Library ini menyediakan berbagai algoritma machine learning, termasuk PCA untuk reduksi dimensi dan K-Means untuk mengelompokkan data berdasarkan kemiripan karakteristik fitur.

Dalam proses ini, data hasil ekstraksi fitur polutan CO, NO₂, dan SO₂ digunakan sebagai masukan. Sebelum proses clustering dilakukan, data dipersiapkan melalui standardisasi dan reduksi dimensi sehingga fitur yang digunakan berada pada skala yang sesuai.

A. Penentuan Jumlah Cluster Menggunakan Elbow Method#

Untuk menentukan jumlah cluster yang akan digunakan dalam proses K-Means, dilakukan evaluasi menggunakan Elbow Method. Metode ini menguji beberapa nilai jumlah cluster dan menghitung nilai inertia yang dihasilkan oleh masing-masing model.

Pengujian dilakukan dengan mencoba jumlah cluster mulai dari \(K=2\) hingga \(K=10\). Setiap nilai \(K\) menghasilkan nilai inertia yang berbeda. Inertia menunjukkan total jarak kuadrat antara setiap data dengan centroid dari cluster tempat data tersebut berada.

NO2

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

from google.colab import files
uploaded = files.upload()

nama_file = list(uploaded.keys())[0]
df = pd.read_csv(nama_file)

fitur = df.drop(['id', 'nama', 'daerah'], axis=1)

scaler = StandardScaler()
fitur_scaled = scaler.fit_transform(fitur)

fitur_pca = PCA(n_components=37).fit_transform(fitur_scaled)

inertia = []
K_range = range(2, 11)

for k in K_range:
    kmeans_temp = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )
    kmeans_temp.fit(fitur_pca)
    inertia.append(kmeans_temp.inertia_)

plt.figure(figsize=(8, 5))
plt.plot(K_range, inertia, marker='o', linestyle='--')
plt.title('Evaluasi Jumlah Cluster dengan Elbow Method')
plt.xlabel('Jumlah Cluster (K)')
plt.ylabel('Inersia (Jarak Kuadrat)')
plt.grid(True)
plt.show()

B. Visualisasi Scatter Plot PCA dan Profiling#

Setelah jumlah cluster yang akan digunakan ditentukan melalui Elbow Method, tahap berikutnya adalah menerapkan algoritma K-Means menggunakan jumlah cluster tersebut. Hasil pengelompokan kemudian divisualisasikan menggunakan Scatter Plot PCA.

Visualisasi ini menggunakan PCA 1 sebagai sumbu X dan PCA 2 sebagai sumbu Y. Dengan demikian, persebaran data pada dua komponen utama dapat diamati untuk melihat pola dan kedekatan antarcluster.

Selain visualisasi, dilakukan pula profiling cluster untuk mengetahui karakteristik masing-masing kelompok berdasarkan fitur yang digunakan dalam proses clustering. Hasil profiling dapat digunakan untuk memahami perbedaan karakteristik data pada setiap cluster.

NO2

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from google.colab import files

# 1. Memilih file hasil ekstraksi fitur
uploaded = files.upload()
nama_file = list(uploaded.keys())[0]

df = pd.read_csv(nama_file)

# Memisahkan identitas dan fitur
identitas = df[['id', 'nama', 'daerah']]
fitur = df.drop(['id', 'nama', 'daerah'], axis=1)

# 2. Standardisasi dan PCA
scaler = StandardScaler()
fitur_scaled = scaler.fit_transform(fitur)

pca = PCA(n_components=37)
fitur_pca = pca.fit_transform(fitur_scaled)

# 3. K-Means
kmeans = KMeans(
    n_clusters=6,
    random_state=42,
    n_init=10
)

clusters = kmeans.fit_predict(fitur_pca)

# Menyimpan hasil cluster
df_hasil = identitas.copy()
df_hasil['Cluster'] = clusters

# 4. Visualisasi Scatter Plot
plt.figure(figsize=(15, 7))

sns.scatterplot(
    data=df_hasil,
    x='daerah',
    y='Cluster',
    hue='Cluster',
    palette='tab10',
    s=100
)

plt.title('Scatter Plot Persebaran Daerah Berdasarkan Cluster')
plt.xlabel('Nama Daerah')
plt.ylabel('Cluster')
plt.xticks(rotation=90)
plt.legend(title='Cluster')
plt.grid(True)
plt.show()

# 5. Profiling cluster berdasarkan daerah
profil_daerah = (
    df_hasil
    .groupby(['Cluster', 'daerah'])
    .size()
    .reset_index(name='Jumlah')
)

top_3_per_cluster = (
    profil_daerah
    .sort_values(
        by=['Cluster', 'Jumlah'],
        ascending=[True, False]
    )
    .groupby('Cluster')
    .head(3)
)

print('Profil 3 daerah teratas pada setiap cluster:')
print(top_3_per_cluster)

2. Tahapan Proses Clustering Menggunakan KNIME#

Proses clustering dilakukan menggunakan KNIME melalui beberapa tahapan. Data terlebih dahulu dihubungkan dari PostgreSQL, kemudian tabel dan fitur yang digunakan dipilih. Data selanjutnya dibaca dan direduksi dimensinya menggunakan PCA. Setelah itu, K-Means digunakan untuk mengelompokkan data berdasarkan kemiripan karakteristik. Hasil clustering kemudian ditampilkan menggunakan Scatter Plot untuk melihat persebaran setiap cluster.

  1. PostgreSQL Connector
    Menghubungkan KNIME dengan database PostgreSQL pada Aiven.

  2. DB Table Selector
    Memilih tabel data hasil ekstraksi fitur yang akan digunakan.

  3. DB Reader
    Membaca dan mengambil data dari tabel PostgreSQL ke dalam workflow KNIME.

  4. PCA
    Melakukan reduksi dimensi untuk menyederhanakan jumlah fitur sebelum clustering.

  5. K-Means
    Mengelompokkan data berdasarkan kemiripan karakteristik fitur.

  6. Scatter Plot
    Menampilkan hasil clustering dalam bentuk visual agar persebaran setiap cluster dapat diamati.

3. Visualisasi Pembagian Cluster Polutan#

Hasil K-Means pada data NO₂, CO, dan SO₂ ditampilkan melalui Scatter Plot. Grafik ini menunjukkan pembagian setiap daerah ke dalam cluster berdasarkan karakteristik fitur yang digunakan. Dari visualisasi tersebut dapat dilihat persebaran data pada masing-masing cluster.

a. Hasil Clustering NO₂

Berdasarkan visualisasi polutan NO₂, algoritma K-Means membagi data menjadi 6 cluster, yaitu cluster_0 hingga cluster_5.

Beberapa insight yang dapat dilihat dari grafik:

  • Cluster 4 memiliki persebaran paling banyak: Titik pada cluster_4 terlihat tersebar di berbagai daerah dan menjadi kelompok yang cukup dominan dibandingkan cluster lainnya.

  • Cluster 5 hanya memiliki satu titik: Cluster_5 terlihat berada pada bagian paling bawah dan hanya muncul pada satu daerah. Hal ini menunjukkan adanya data dengan karakteristik yang cukup berbeda dari kelompok lainnya.

  • Cluster 0 memiliki beberapa anggota: Beberapa daerah juga masuk ke cluster_0, yang menunjukkan adanya kemiripan karakteristik fitur NO₂ pada data tersebut.

  • Cluster lainnya memiliki jumlah anggota lebih sedikit: Cluster_1, cluster_2, dan cluster_3 hanya berisi beberapa titik. Artinya, karakteristik yang dimiliki kelompok tersebut lebih spesifik dibandingkan cluster yang lebih dominan.

b. Hasil Clustering CO

Pada grafik CO, data terbagi menjadi 4 cluster dengan persebaran yang tidak merata.

  • Cluster_0 memiliki jumlah titik yang jauh lebih banyak dibandingkan cluster lainnya dan mencakup sebagian besar daerah.

  • Cluster_3 hanya muncul pada beberapa daerah, sedangkan cluster_2 dan cluster_1 memiliki anggota yang lebih sedikit.

  • Pola tersebut menunjukkan bahwa sebagian besar data CO memiliki karakteristik yang serupa, sementara beberapa data lainnya membentuk kelompok tersendiri.

c. Hasil Clustering SO₂

Hasil pengelompokan data SO₂ menunjukkan adanya 6 cluster dengan pola persebaran yang lebih beragam.

  • Cluster_5 dan cluster_1 terlihat memiliki jumlah titik yang cukup banyak dibandingkan cluster lainnya.

  • Cluster_2 hanya terdiri dari beberapa titik yang berada pada daerah tertentu.

  • Cluster_0, cluster_3, dan cluster_4 memiliki jumlah anggota yang lebih sedikit dan cenderung muncul pada posisi tertentu.

  • Perbedaan jumlah anggota tersebut menunjukkan bahwa karakteristik data SO₂ terbagi ke dalam beberapa pola yang berbeda.
