Ekstraksi Fitur TSFEL pada 3 Polutan#

Data pada tugas sebelumnya belum mencakup 366 hari sehingga pada tahap lanjutan ini data dari masing-masing polutan disesuaikan ke rentang tanggal yang sama, yaitu 31 Agustus 2025 sampai 31 Agustus 2026.

File NO2, CO, dan SO2 dimasukkan secara terpisah. Kolom date kemudian diubah menjadi format tanggal dan data diurutkan berdasarkan tanggal.

Selanjutnya dibuat daftar tanggal harian sebanyak 366 tanggal. Data dari ketiga polutan di-reindex menggunakan daftar tanggal tersebut. Jika pada tanggal tertentu data belum tersedia, posisi tersebut menjadi NaN.

Setelah itu ketiga polutan digabungkan menjadi satu dataset dengan struktur date, CO, NO2, dan SO2.

Pada hasil pemeriksaan, jumlah baris sudah menjadi 366, tetapi masih terdapat data yang kosong. Missing value tersebut belum diisi pada tahap ini karena akan ditangani pada proses cleaning berikutnya.

Data hasil penyesuaian kemudian disimpan dalam file Data_Polutan_Kalianget_366.csv.

Pemeriksaan Missing Value dan Outlier#

Setelah dataset memiliki 366 hari, tahap berikutnya adalah melakukan cleaning data pada CO, NO2, dan SO2.

Pertama, data dibaca dari Data_Polutan_Kalianget_366.csv, kemudian kolom date dikonversi menjadi tanggal dan data diurutkan kembali.

Untuk setiap polutan, jumlah missing value sebelum cleaning diperiksa. Setelah itu digunakan metode Interquartile Range (IQR) untuk mendeteksi outlier.

Nilai IQR dihitung dengan:

IQR = Q3 - Q1

Kemudian ditentukan batas:

Batas bawah = Q1 - 1.5 × IQR

Batas atas = Q3 + 1.5 × IQR

Nilai yang berada di luar kedua batas tersebut dianggap sebagai outlier. Outlier tidak langsung dihapus, tetapi diubah menjadi NaN sehingga dapat diproses bersama missing value.

Setelah itu, data menggunakan date sebagai index dan dilakukan interpolasi berdasarkan waktu dengan interpolate(method="time"). Jika masih terdapat nilai kosong pada bagian awal atau akhir, digunakan ffill() dan bfill().

Setelah proses tersebut, jumlah missing value diperiksa kembali. Data juga diperiksa untuk memastikan jumlah baris tetap 366 dan tidak terdapat missing value.

Hasil cleaning disimpan sebagai Data_Polutan_Kalianget_Linear_Clean_366.csv.

import pandas as pd
import numpy as np

df = pd.read_csv("Data_Polutan_Kalianget_366.csv")

df["date"] = pd.to_datetime(df["date"])
df = df.sort_values("date").reset_index(drop=True)

for pollutant in ["CO", "NO2", "SO2"]:

    print("\n==============================================")
    print("PEMERIKSAAN", pollutant)
    print("==============================================")

    print("Missing sebelum cleaning:",
          df[pollutant].isna().sum())

    Q1 = df[pollutant].quantile(0.25)
    Q3 = df[pollutant].quantile(0.75)

    IQR = Q3 - Q1

    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR

    outlier_mask = (
        (df[pollutant] < lower_bound) |
        (df[pollutant] > upper_bound)
    )

    print("Q1 =", Q1)
    print("Q3 =", Q3)
    print("IQR =", IQR)
    print("Batas bawah =", lower_bound)
    print("Batas atas =", upper_bound)
    print("Jumlah outlier =", outlier_mask.sum())

    display(
        df.loc[outlier_mask, ["date", pollutant]]
    )

    df.loc[outlier_mask, pollutant] = np.nan

    print(
        "Jumlah missing setelah outlier ditandai:",
        df[pollutant].isna().sum()
    )

    df = df.set_index("date")

    df[pollutant] = (
        df[pollutant]
        .interpolate(method="time")
        .ffill()
        .bfill()
    )

    df = df.reset_index()

    print(
        "Jumlah missing setelah imputasi:",
        df[pollutant].isna().sum()
    )

print("\n==============================================")
print("HASIL PEMERIKSAAN DATA SETELAH CLEANING")
print("==============================================")

for pollutant in ["CO", "NO2", "SO2"]:

    Q1_final = df[pollutant].quantile(0.25)
    Q3_final = df[pollutant].quantile(0.75)

    IQR_final = Q3_final - Q1_final

    lower_final = Q1_final - 1.5 * IQR_final
    upper_final = Q3_final + 1.5 * IQR_final

    final_outlier_mask = (
        (df[pollutant] < lower_final) |
        (df[pollutant] > upper_final)
    )

    jumlah_missing_final = df[pollutant].isna().sum()
    jumlah_outlier_final = final_outlier_mask.sum()

    print("\n", pollutant)
    print("Missing value :", jumlah_missing_final)
    print("Outlier       :", jumlah_outlier_final)

print("\n==============================================")
print("JUMLAH BARIS :", len(df))
print("==============================================")

if (
    len(df) == 366 and
    df[["CO", "NO2", "SO2"]].isna().sum().sum() == 0
):
    print("Data sudah clean, berjumlah 366 hari, dan tanpa missing value.")
else:
    print("Data masih perlu diperiksa.")

display(df.head())
display(df.tail())

nama_file = "Data_Polutan_Kalianget_Linear_Clean_366.csv"

df.to_csv(nama_file, index=False)

print("\nFile berhasil disimpan sebagai:", nama_file)

Preprocessing Linear dan Polynomial#

Setelah data 366 hari selesai melalui proses cleaning, tahap berikutnya membuat dua bentuk hasil preprocessing, yaitu Linear dan Polynomial.

Linear Interpolation#

Pada bagian Linear, dataset hasil input dibaca terlebih dahulu dan jumlah missing value sebelum preprocessing ditampilkan.

Setiap nilai polutan dikonversi menjadi numerik menggunakan pd.to_numeric(). Nilai yang tidak dapat dikonversi akan menjadi NaN.

Kemudian missing value diisi menggunakan:

interpolate(method="linear")

Interpolasi linear memperkirakan nilai kosong berdasarkan hubungan linear antara nilai yang tersedia sebelum dan sesudahnya. ffill() dan bfill() digunakan untuk melengkapi nilai kosong yang mungkin masih berada di bagian awal atau akhir data.

Hasilnya disimpan sebagai:

Data_Polutan_Kalianget_Linear_366.csv

Polynomial Interpolation#

Pada bagian Polynomial, data juga dikonversi menjadi numerik. Posisi setiap baris dibuat menggunakan np.arange() sebagai variabel x, sedangkan nilai polutan digunakan sebagai y.

Data yang bukan NaN digunakan untuk membentuk polinomial menggunakan np.polyfit() dengan derajat 2.

Model tersebut kemudian digunakan untuk memperkirakan nilai pada posisi yang masih kosong.

Hasilnya disimpan sebagai:

Data_Polutan_Kalianget_Polynomial_366.csv

Dengan demikian tersedia dua dataset hasil preprocessing yang dapat digunakan pada tahap ekstraksi fitur.

import pandas as pd
import numpy as np
from google.colab import files

uploaded = files.upload()
filename = next(iter(uploaded))

df = pd.read_csv(filename)

df['date'] = pd.to_datetime(df['date'])
df = df.sort_values('date').reset_index(drop=True)

pollutants = ['CO', 'NO2', 'SO2']

print("Jumlah data:", len(df))
print("Jumlah NaN sebelum preprocessing:")
print(df[pollutants].isna().sum())

# =========================
# LINEAR
# =========================

df_linear = df.copy()

for pollutant in pollutants:
    df_linear[pollutant] = pd.to_numeric(
        df_linear[pollutant],
        errors='coerce'
    )

    df_linear[pollutant] = (
        df_linear[pollutant]
        .interpolate(method='linear')
        .ffill()
        .bfill()
    )

print("\nNaN setelah Linear:")
print(df_linear[pollutants].isna().sum())

df_linear.to_csv(
    'Data_Polutan_Kalianget_Linear_366.csv',
    index=False
)

# =========================
# POLYNOMIAL
# =========================

df_polynomial = df.copy()

for pollutant in pollutants:
    df_polynomial[pollutant] = pd.to_numeric(
        df_polynomial[pollutant],
        errors='coerce'
    )

    x = np.arange(len(df_polynomial))
    y = df_polynomial[pollutant].values

    valid = ~np.isnan(y)

    if valid.sum() >= 3:
        degree = 2

        koef = np.polyfit(
            x[valid],
            y[valid],
            degree
        )

        model = np.poly1d(koef)

        missing = np.isnan(y)
        y[missing] = model(x[missing])

    df_polynomial[pollutant] = y

print("\nNaN setelah Polynomial:")
print(df_polynomial[pollutants].isna().sum())

df_polynomial.to_csv(
    'Data_Polutan_Kalianget_Polynomial_366.csv',
    index=False
)

print("\nFile berhasil dibuat:")
print("1. Data_Polutan_Kalianget_Linear_366.csv")
print("2. Data_Polutan_Kalianget_Polynomial_366.csv")

files.download('Data_Polutan_Kalianget_Linear_366.csv')
files.download('Data_Polutan_Kalianget_Polynomial_366.csv')

Ekstraksi Fitur Time Series dengan TSFEL#

Pada tahap ini data hasil preprocessing digunakan untuk menghasilkan fitur time series menggunakan TSFEL.

Data yang diproses terdiri dari tiga polutan:

  • NO2

  • SO2

  • CO

Nilai fs = 1 digunakan sebagai frekuensi sampling pada proses ekstraksi fitur.

Daftar fitur#

FEATURE_LIST berisi kumpulan fitur yang akan dihitung untuk setiap polutan. Fitur tersebut mencakup karakteristik statistik, temporal, frekuensi, spektral, wavelet, dan karakteristik time series lainnya.

Jumlah fitur per polutan dihitung dari panjang FEATURE_LIST, kemudian jumlah tersebut dikalikan dengan jumlah polutan untuk mendapatkan target jumlah fitur keseluruhan.

Menyiapkan fungsi ekstraksi#

Fungsi to_scalar() digunakan untuk memastikan hasil setiap fitur menjadi satu nilai numerik. Jika hasil fitur berupa array, list, tuple, atau dictionary yang memiliki values, hasil tersebut dikonversi dan diringkas menjadi nilai rata-rata.

Fungsi extract_one() mengambil fungsi fitur TSFEL berdasarkan nama fitur. inspect.signature() digunakan untuk memeriksa apakah fungsi tersebut membutuhkan parameter fs.

Cleaning sebelum ekstraksi#

Untuk setiap polutan, data diambil bersama kolom tanggal dan dikonversi menjadi numerik.

Outlier kembali diperiksa menggunakan metode IQR. Nilai yang berada di luar batas IQR diubah menjadi NaN.

Data kemudian menggunakan tanggal sebagai index dan dilakukan interpolasi berbasis waktu, dilanjutkan dengan ffill() dan bfill().

Hasil akhirnya disimpan dalam signal_1d, yaitu data satu dimensi yang digunakan sebagai input untuk fungsi-fungsi TSFEL.

Pembentukan fitur#

Setiap fitur pada FEATURE_LIST dihitung untuk masing-masing polutan. Nama kolom hasil dibuat dengan format:

nama_polutan_nama_fitur

Contohnya adalah NO2_calc_mean, SO2_entropy, atau CO_rms.

Seluruh hasil fitur dari ketiga polutan digabungkan menjadi satu baris pada DataFrame extracted_features_final.

Dataset hasil ekstraksi kemudian disimpan sebagai:

All-Pollutants-Kalianget-TSFEL.csv

File tersebut menjadi hasil akhir ekstraksi fitur dari data polutan yang telah diproses.

import pandas as pd
import numpy as np
import inspect
from google.colab import files
import tsfel.feature_extraction.features as tsfel_features

uploaded = files.upload()
filename = next(iter(uploaded))

df = pd.read_csv(filename)

df['date'] = pd.to_datetime(df['date'])
df = df.sort_values('date').reset_index(drop=True)

pollutants = ['NO2', 'SO2', 'CO']
fs = 1

FEATURE_LIST = """abs_energy auc autocorr average_power calc_centroid calc_max calc_mean
calc_median calc_min calc_std calc_var dfa distance ecdf ecdf_percentile ecdf_percentile_count
ecdf_slope entropy fundamental_frequency higuchi_fractal_dimension hist_mode human_range_energy
hurst_exponent interq_range kurtosis lempel_ziv lpcc max_frequency max_power_spectrum
maximum_fractal_length mean_abs_deviation mean_abs_diff mean_diff median_abs_deviation
median_abs_diff median_diff median_frequency mfcc mse negative_turning neighbourhood_peaks
petrosian_fractal_dimension pk_pk_distance positive_turning power_bandwidth rms skewness slope
spectral_centroid spectral_decrease spectral_distance spectral_entropy spectral_kurtosis
spectral_positive_turning spectral_roll_off spectral_roll_on spectral_skewness spectral_slope
spectral_spread spectral_variation spectrogram_mean_coeff sum_abs_diff wavelet_abs_mean
wavelet_energy wavelet_entropy wavelet_std wavelet_var zero_cross""".split()

print(f"Jumlah fitur per polutan: {len(FEATURE_LIST)}")
print(f"Total target fitur keseluruhan: {len(FEATURE_LIST) * len(pollutants)}")


def to_scalar(result):
    if isinstance(result, dict) and "values" in result:
        result = result["values"]

    if isinstance(result, (list, tuple, np.ndarray)):
        arr = np.asarray(result, dtype=float)
        return float(np.nanmean(arr))

    return float(result)


def extract_one(fn_name, signal, fs):
    fn = getattr(tsfel_features, fn_name)
    params = inspect.signature(fn).parameters

    if "fs" in params:
        result = fn(signal, fs)
    else:
        result = fn(signal)

    return to_scalar(result)


combined_row = {}

for pollutant in pollutants:
    print(f"\n--- Memproses polutan: {pollutant} ---")

    df_poly = df[['date', pollutant]].copy()

    df_poly[pollutant] = pd.to_numeric(
        df_poly[pollutant],
        errors='coerce'
    )

    n_missing_before = df_poly[pollutant].isna().sum()
    print(f"Jumlah NaN/non-numerik pada {pollutant}: {n_missing_before}")

    Q1 = df_poly[pollutant].quantile(0.25)
    Q3 = df_poly[pollutant].quantile(0.75)
    IQR = Q3 - Q1

    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR

    df_poly.loc[
        (df_poly[pollutant] < lower_bound) |
        (df_poly[pollutant] > upper_bound),
        pollutant
    ] = np.nan

    df_clean = (
        df_poly
        .set_index('date')
        .interpolate(method='time')
        .ffill()
        .bfill()
    )

    signal_1d = df_clean[pollutant].astype(float).values

    print(f"Jumlah data setelah cleaning: {len(signal_1d)}")
    print(f"Jumlah NaN setelah cleaning: {np.isnan(signal_1d).sum()}")

    for fn_name in FEATURE_LIST:
        feature_key = f"{pollutant}_{fn_name}"
        combined_row[feature_key] = extract_one(
            fn_name,
            signal_1d,
            fs
        )

extracted_features_final = pd.DataFrame([combined_row])

print(
    f"\nBerhasil! Total kolom akhir yang dihasilkan: "
    f"{extracted_features_final.shape[1]}"
)

output_filename = 'All-Pollutants-Kalianget-TSFEL.csv'

extracted_features_final.to_csv(
    output_filename,
    index=False
)

print(f"File berhasil disimpan sebagai: {output_filename}")

files.download(output_filename)

Eksperimen Reduksi Dimensi, Evaluasi Klaster, dan Pemetaan Segmentasi Multi-Polutan#

Dokumen ini menjelaskan proses analisis data gabungan dari tiga jenis polutan udara yang telah melalui proses ekstraksi fitur hingga menghasilkan 204 fitur. Data yang digunakan terdiri dari dua hasil pengolahan, yaitu data linier dan data polinomial.

Pengolahan data dilakukan menggunakan KNIME Analytics Platform dengan beberapa node untuk melakukan reduksi dimensi, clustering, evaluasi, dan visualisasi. Tahapan pengolahan data adalah sebagai berikut:

  1. Mengambil dataset linier dan polinomial dari database MySQL menggunakan node MySQL Connector, DB Table Selector, dan DB Reader.

  2. Melakukan reduksi dimensi menggunakan node PCA dengan tiga skenario jumlah dimensi, yaitu 203 dimensi, 74 dimensi, dan 37 dimensi pada masing-masing dataset linier dan polinomial.

  3. Melakukan proses clustering menggunakan node K-Means pada setiap hasil PCA untuk mengelompokkan 37 titik pengamatan berdasarkan karakteristik fitur multi-polutan.

  4. Melakukan eksperimen terhadap beberapa nilai K (jumlah cluster) menggunakan proses looping, kemudian mengevaluasi hasil clustering menggunakan Silhouette Coefficient untuk menentukan jumlah cluster yang paling optimal.

  5. Menggunakan hasil clustering dengan nilai Silhouette Coefficient terbaik sebagai hasil segmentasi wilayah dari 37 titik pengamatan.

  6. Menampilkan hasil pengelompokan dan segmentasi menggunakan node Scatter Plot serta memvisualisasikan hasil cluster pada peta berdasarkan wilayah pengamatan.

1. Alur Workflow Eksperimen KNIME#

  1. MySQL Connector

Node MySQL Connector digunakan untuk menghubungkan KNIME dengan database MySQL yang menyimpan dataset hasil preprocessing dan ekstraksi fitur. Koneksi ini menjadi tahap awal untuk mengambil data yang akan digunakan dalam proses clustering.

  1. DB Table Selector

Node DB Table Selector digunakan untuk memilih tabel yang akan digunakan dalam proses pengolahan. Data yang digunakan berasal dari hasil ekstraksi fitur tiga polutan, yaitu CO, NO₂, dan SO₂, dengan dua jenis pengolahan, yaitu data LINIER dan POLYNOMIAL.

  1. DB Reader

Node DB Reader digunakan untuk membaca data dari tabel yang telah dipilih sehingga data dapat diteruskan ke tahap reduksi dimensi.

  1. Principal Component Analysis (PCA)

Data yang telah dibaca kemudian diproses menggunakan PCA (Principal Component Analysis). Reduksi dimensi dilakukan dengan tiga skenario, yaitu 203 dimensi, 74 dimensi, dan 37 dimensi.

Proses ini diterapkan pada masing-masing jalur data LINIER dan POLYNOMIAL, sehingga terdapat enam konfigurasi PCA yang diuji:

  • LINIER 203 dimensi

  • LINIER 74 dimensi

  • LINIER 37 dimensi

  • POLYNOMIAL 203 dimensi

  • POLYNOMIAL 74 dimensi

  • POLYNOMIAL 37 dimensi

  1. Counting Loop Start

Setiap hasil PCA kemudian masuk ke proses eksperimen menggunakan Counting Loop Start. Proses looping dilakukan sebanyak 5 iterasi untuk menguji beberapa jumlah klaster.

  1. Math Formula (Variable)

Node Math Formula (Variable) digunakan untuk menentukan nilai jumlah klaster berdasarkan nilai iterasi. Nilai yang digunakan adalah:

\[ K = currentIteration + 2 \]

Dengan demikian, proses looping menghasilkan nilai K = 2, 3, 4, 5, dan 6.

  1. K-Means

Nilai K yang dihasilkan dari proses looping diteruskan ke node K-Means melalui flow variable. K-Means kemudian melakukan pengelompokan data berdasarkan jumlah klaster yang sedang diuji.

Pada proses ini digunakan Random sebagai metode inisialisasi centroid, seed 12345, dan maksimum 100 iterasi.

  1. Silhouette Coefficient

Hasil pengelompokan dari K-Means selanjutnya dievaluasi menggunakan node Silhouette Coefficient. Evaluasi dilakukan untuk mengetahui kualitas pemisahan data pada setiap klaster.

Nilai Silhouette digunakan untuk membandingkan kualitas clustering pada setiap nilai K yang diuji. Semakin tinggi nilai yang diperoleh, semakin baik kualitas pengelompokan data.

  1. Constant Value Column Filter

Node Constant Value Column Filter digunakan untuk menyaring kolom yang memiliki nilai konstan pada hasil proses evaluasi sehingga data yang diteruskan ke tahap berikutnya lebih relevan.

  1. Loop End

Node Loop End digunakan untuk menggabungkan hasil dari seluruh iterasi. Hasil dari K = 2 hingga K = 6 kemudian dapat dibandingkan berdasarkan nilai Silhouette Coefficient.

  1. Penentuan Hasil Clustering Terbaik

Nilai Silhouette dari seluruh konfigurasi dibandingkan untuk menentukan hasil clustering terbaik. Berdasarkan eksperimen yang dilakukan, konfigurasi dengan nilai Silhouette tertinggi dipilih sebagai konfigurasi clustering yang paling optimal.

Pada jalur LINIER, nilai tertinggi diperoleh pada K = 2 dan 203 dimensi dengan nilai Silhouette sebesar 0.8219196103. Sementara itu, pada jalur POLYNOMIAL, nilai tertinggi diperoleh pada K = 2 dengan nilai sebesar 0.6343256560.

Dengan demikian, konfigurasi terbaik dari seluruh eksperimen adalah jalur LINIER dengan 203 dimensi dan K = 2.

  1. Visualisasi dan Pemetaan Hasil Clustering

Hasil clustering terbaik kemudian digunakan untuk melakukan segmentasi terhadap 37 titik pengamatan. Setiap titik pengamatan diberikan label cluster berdasarkan hasil K-Means.

Selanjutnya, label cluster digabungkan dengan informasi koordinat latitude dan longitude untuk menampilkan hasil segmentasi dalam bentuk peta. Peta tersebut digunakan untuk melihat persebaran setiap cluster pada wilayah pengamatan.

2. Evaluasi dan Penentuan Klaster Optimal Berdasarkan Silhouette Coefficient#

Evaluasi kualitas clustering pada setiap iterasi dilakukan menggunakan nilai Silhouette Coefficient. Nilai Silhouette digunakan untuk mengetahui tingkat kedekatan suatu data dengan anggota klaster yang sama serta jaraknya terhadap klaster lain. Perhitungan Silhouette Coefficient menggunakan persamaan berikut:

\[ s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}} \]

dengan:

  • \(s(i)\) = nilai Silhouette Coefficient untuk data ke-\(i\).

  • \(a(i)\) = rata-rata jarak data ke-\(i\) terhadap data lain dalam klaster yang sama.

  • \(b(i)\) = rata-rata jarak minimum data ke-\(i\) terhadap data pada klaster lain.

Nilai Silhouette Coefficient berada pada rentang -1 hingga 1. Nilai yang semakin mendekati 1 menunjukkan bahwa data memiliki kedekatan yang lebih tinggi dengan klasternya sendiri dan pemisahan yang lebih baik dari klaster lainnya. Oleh karena itu, nilai Silhouette tertinggi digunakan sebagai salah satu dasar dalam menentukan konfigurasi klaster yang paling optimal.

C. Analisis dan Interpretasi Hasil Clustering#

Hasil eksperimen menunjukkan bahwa kualitas clustering pada jalur fitur LINIER dan POLYNOMIAL berbeda berdasarkan nilai Silhouette Coefficient yang diperoleh pada setiap jumlah klaster. Pada jalur LINIER, nilai Silhouette tertinggi diperoleh pada K = 2 dengan nilai 0.8219196103 pada 203 dimensi. Sementara itu, pada jalur POLYNOMIAL, nilai tertinggi juga diperoleh pada K = 2, tetapi dengan nilai 0.6343256560. Hal ini menunjukkan bahwa konfigurasi dua klaster menghasilkan pemisahan kelompok yang paling baik pada kedua jenis fitur.

Pada jalur fitur LINIER, nilai Silhouette mengalami penurunan ketika jumlah klaster bertambah dari K = 2 hingga K = 5. Nilainya berturut-turut sebesar 0.8219196103, 0.6468671205, 0.5974287820, dan 0.5208039968. Pada K = 6, nilai Silhouette mengalami sedikit peningkatan menjadi 0.5719908597, tetapi masih lebih rendah dibandingkan K = 2. Pola tersebut menunjukkan bahwa penambahan jumlah klaster tidak secara otomatis menghasilkan pengelompokan yang lebih baik. Dalam eksperimen ini, dua klaster memberikan struktur kelompok yang paling jelas berdasarkan karakteristik fitur yang digunakan.

Pada jalur POLYNOMIAL, nilai Silhouette pada K = 2 juga menjadi yang paling tinggi, yaitu 0.6343256560. Nilai tersebut kemudian menurun menjadi 0.4589385555 pada K = 3 dan 0.4726391315 pada K = 4. Nilai kembali meningkat pada K = 5 menjadi 0.5053289256 dan K = 6 menjadi 0.5619463280, tetapi belum melampaui nilai pada K = 2. Dengan demikian, hasil eksperimen menunjukkan bahwa konfigurasi K = 2 tetap menjadi pilihan terbaik untuk jalur fitur POLYNOMIAL.

Perbandingan antara kedua jalur menunjukkan bahwa fitur LINIER menghasilkan nilai Silhouette yang lebih tinggi dibandingkan fitur POLYNOMIAL pada seluruh konfigurasi jumlah klaster yang diuji. Nilai tertinggi pada fitur LINIER mencapai 0.8219196103, sedangkan fitur POLYNOMIAL mencapai 0.6343256560. Perbedaan tersebut menunjukkan bahwa representasi fitur hasil interpolasi linier menghasilkan pemisahan antar-klaster yang lebih baik dibandingkan representasi hasil interpolasi polinomial pada dataset yang digunakan.

Dari sisi reduksi dimensi, hasil pada jalur POLYNOMIAL menunjukkan nilai Silhouette yang sama pada 203, 74, dan 37 dimensi. Pada jalur LINIER, nilai Silhouette antar-reduksi dimensi juga memiliki nilai yang sangat berdekatan. Hal ini menunjukkan bahwa pengurangan jumlah dimensi tidak memberikan perubahan besar terhadap kualitas clustering pada eksperimen ini. Dengan demikian, reduksi dimensi dapat dilakukan tanpa menyebabkan perubahan signifikan terhadap struktur klaster yang terbentuk.

Berdasarkan keseluruhan eksperimen, konfigurasi yang menghasilkan nilai Silhouette tertinggi adalah jalur fitur LINIER dengan K = 2 pada 203 dimensi, yaitu sebesar 0.8219196103. Konfigurasi tersebut dipilih sebagai hasil clustering terbaik karena memberikan nilai Silhouette paling tinggi dibandingkan seluruh konfigurasi yang diuji. Hasil clustering terbaik tersebut selanjutnya dapat digunakan sebagai dasar untuk melakukan segmentasi 37 titik pengamatan pada peta berdasarkan cluster yang terbentuk.
